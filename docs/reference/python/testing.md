# `indi_nexus.testing`

Test a driver by driving it the way a client would - no `indiserver`, no
sockets, no hardware. See
[Testing your driver](../../guides/writing-drivers.md#testing-your-driver) for
the guide, and `tests/test_weather_example.py` for a worked set.
